## 2026-02-23 - Accessibility in Pixel Art Tools
**Learning:** Pixel-art style applications often prioritize minimal visuals (like icon-only buttons or color swatches), but this creates accessibility gaps for screen readers and color-blind users who cannot perceive the color or function solely from the visual.
**Action:** Always map visual properties (color hex codes, size numbers) to human-readable strings for `aria-label` attributes in toolbar components.
