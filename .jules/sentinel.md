## 2025-02-15 - PII Leakage in Live Adapter Logs
**Vulnerability:** The `GeminiLiveAdapter.js` logged full, unredacted text arrays for `historyText` payloads, `systemInstruction` in `connectConfig`, and full live transcripts (`inputTranscription`, `outputTranscription`).
**Learning:** In adapters and connection builders, extensive configuration logging (such as `connectConfig` which contains `systemInstruction` and `tools`) easily exposes user prompts and history. Transcripts and past messages represent significant PII risk when emitted in plaintext. Simply logging `<redacted>` isn't sufficiently helpful for debugging length-related API errors.
**Prevention:** Shallow clone configuration objects (like `connectConfig`) prior to logging so properties like `systemInstruction` can be replaced with `<redacted length=N>` without modifying the actual live connection context. Apply the `<redacted length=N>` pattern systematically to chat history and transcription payload logs.
