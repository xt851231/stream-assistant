## 2025-05-15 - Sensitive Data in Logs\n**Vulnerability:** Found `GeminiLiveAdapter` and `GeminiFlashAdapter` logging full user transcriptions and AI responses to `console.log`.\n**Learning:** Developers likely used `console.log` for debugging the data flow but forgot to remove or sanitize it for production.\n**Prevention:** Use `console.debug` for verbose logging (strip in prod) or log only metadata (e.g., length) instead of content.
